# Peddle Thorp Architects PNG Ltd — website

Website for Peddle Thorp Architects PNG Ltd, Port Moresby, Papua New Guinea. It follows the design of the partner sites peddlethorp.com.au and ptw.com.au, with a PNG character built around the company's sky-blue logo.

It is a static site: one HTML file, no server code. `index.html` runs as it is on GitHub Pages or any web host.

## Files

- `index.html`: the live site.
- `src/body.html`: the source. Pages, styles, the project list (`PROJECTS`) and news are all here.
- `build.sh`: run `sh build.sh` after editing `src/body.html` to regenerate `index.html` (and `preview.html`, the self-contained preview, which is not committed).
- `images/`: logo and photos. See `images/README.txt` for photo file names.
- `CONTENT-NEEDED.md`: photos, contact details, team and project details still to supply.
